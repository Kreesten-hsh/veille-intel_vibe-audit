Synthèse Exécutive Décideur

L'audit passif de l'environnement LeadFlow Sandbox a mis en évidence deux vulnérabilités d'importance élevée permettant l'extraction non authentifiée de données clients et l'exposition d'une clé d'intégration tierce.

Aucune intrusion active n'a été réalisée. La gestion des sessions utilisateurs (JWT) est robuste. Les composants de paiement Stripe n'ont pas été évalués dans cette mission (hors périmètre). Les correctifs peuvent être déployés en moins d'une heure à l'aide des prompts fournis.

1. Impact Métier & Conséquence
Fuite de données transactionnelles clients
La table orders est accessible en lecture directe sans filtrage d'utilisateur. Tout visiteur non authentifié disposant de la clé publique anon peut extraire l'historique complet des commandes, adresses emails et montants encaissés.

3. Remédiation Immédiate (Prompt & SQL)
Correction proposée
Cible : Lovable / Bolt / Cursor / Supabase SQL Prompt prêt à coller
-- Hypothèse : la table 'orders' possède une colonne 'user_id' liée à auth.users.id Dans Supabase, active la politique Row Level Security (RLS) sur la table 'orders' : ALTER TABLE orders ENABLE ROW LEVEL SECURITY; -- 1. Isolation stricte en lecture pour le propriétaire CREATE POLICY "Lecture réservée au propriétaire" ON orders FOR SELECT USING (auth.uid() = user_id); -- 2. Isolation stricte en insertion CREATE POLICY "Insertion réservée au propriétaire" ON orders FOR INSERT WITH CHECK (auth.uid() = user_id); -- 3. Protection en mise à jour (évite la modification d'ordres tiers) CREATE POLICY "Modification réservée au propriétaire" ON orders FOR UPDATE USING (auth.uid() = user_id);
4. Critères de Validation Post-Déploiement
  • Test 1 (Après correction) : Rejouer la commande curl avec la clé anon. Le serveur doit renvoyer un tableau vide [] ou un code HTTP 401/403.
  • Test 2 (Session utilisateur) : Se connecter avec un compte client : vérifier que ses commandes personnelles restent visibles sans anomalie.
  • Re-contrôle J+14 : Prestation éligible au protocole de vérification gratuite après mise en production réelle des correctifs.
