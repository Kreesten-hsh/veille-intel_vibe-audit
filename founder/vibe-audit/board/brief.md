# Board Brief: Vibe-Audit

## The Idea
Vibe-Audit provides express, fixed-fee cybersecurity audits for web and mobile applications built with AI app builders (Lovable, Bolt.new, Cursor, v0, Bubble).
Non-technical founders using AI vibe coding are shipping apps in hours that collect user passwords, PII, and handle Stripe/payment webhooks, frequently leaving massive security holes (e.g. Supabase Row Level Security disabled, API keys exposed in client bundles, IDOR, unauthenticated endpoints).
Vibe-Audit delivers an actionable French security audit report within 48 hours for 249 € (intro pilot at 99 €), translating technical flaws into copy-paste prompt fixes that founders can directly feed back to their AI coding tool.

## Value Proposition & Deliverable
- 48-hour turnaround time.
- Severity-ranked findings (Critical, High, Medium, Low).
- Each finding includes: reproducible proof, business impact, remediation steps, and an exact prompt ready to paste into Lovable/Bolt/Cursor.
- List of untested surfaces (transparent attack perimeter).
- Free follow-up re-check at Day 14.
- AI-assisted analysis verified and signed by a human operator (mandatory disclosure).
- Absolute legal requirement: written founder consent obtained before testing. No destructive testing or intrusive brute force.

## Pricing & Commercial Model
- Pilot: 99 € (strictly first 2 clients in exchange for public testimonial/review).
- Standard: 249 € (audit + report + J+14 re-check).
- Restitution: 399 € (Standard + 30-min live video debrief).
- Invoicing: International sole proprietor invoice, prepaid by SEPA wire transfer (Moneco / Ecobank).

## Operator & Production Engine
- Solo operator: Kreesten (computer software degree, training in information security).
- Workspace includes reference vulnerable test application (`work/demo-vulnerable-app`).
- Budget: Exactly 0 € spend. Reliance on open-source static analyzers, manual code review, proxy inspection, and LLM synthesis.

## Target & Timeline
- Hard deadline: December 31, 2026 (~2.5 months).
- Complementary role: paired with Veille-Intel to hit the 2,000,000 FCFA total target (~3,049 €).
- Volume needed: 2 pilots (198 €) + 5 to 6 standard audits (~1,245 € to ~1,494 €) to inject ~1,400 € to ~1,700 € of immediate cash.
